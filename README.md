# Αντίστροφο Λεξικό — «Περιγράφω την Έννοια, Βρίσκω τη Λέξη»

Εργασία μαθήματος «Σύγχρονες Διαδικτυακές Υπηρεσίες» (2026–27), θέμα 11.
Ο χρήστης περιγράφει μια έννοια και παίρνει 10 υποψήφιες λέξεις με τον ορισμό τους από το
Λεξικό της Κοινής Νεοελληνικής (Τριανταφυλλίδη).

## Πώς δουλεύει

1. **Χωρισμός σε σημασίες** (`src/split_senses.py`): τα 46.745 λήμματα του λεξικού γίνονται
   77.039 σημασίες (ορισμός, συνώνυμα, ετικέτες), με κανόνες που προέκυψαν από χειροκίνητη
   εξερεύνηση 31 λημμάτων.
2. **Embeddings** (`colab/step4_embeddings.ipynb`, Google Colab): κάθε σημασία γίνεται διάνυσμα
   «νοήματος». Σύγκριση 4 μοντέλων σε 20 περιγραφές-δοκιμής → επιλογή του
   `intfloat/multilingual-e5-large` (σωστή λέξη στις 10 πρώτες: 80%, έναντι 30% για απλή
   σύγκριση γραμμάτων). Αποτελέσματα στο `results/step4/`.
3. **Σελίδα αναζήτησης** (`webapp/`, Streamlit Community Cloud): η περιγραφή γίνεται διάνυσμα με
   το ίδιο μοντέλο (ONNX, quantized) και συγκρίνεται με όλους τους ορισμούς.

## Δεδομένα και άδεια

- Πηγή: glossAPI / Mozilla Data Collective — `modern-greek-dictionary`.
- Άδεια: CC BY-NC-ND 4.0 (μόνο μη εμπορική χρήση). Δικαιώματα: Ινστιτούτο Νεοελληνικών
  Σπουδών, ΑΠΘ. Για τον λόγο αυτό τα δεδομένα **δεν** βρίσκονται σε αυτό το αποθετήριο: η
  εφαρμογή τα φορτώνει από ιδιωτικό αποθετήριο δεδομένων στο Hugging Face.

## Δομή

| Φάκελος / αρχείο | Περιεχόμενο |
| --- | --- |
| `src/parquet_reader.py` | Μικρός αναγνώστης parquet χωρίς εξωτερικές βιβλιοθήκες |
| `src/split_senses.py` | Χωρισμός λημμάτων σε σημασίες |
| `src/review_workbook.py` | Excel ελέγχου του χωρισμού |
| `colab/` | Notebook υπολογισμού και σύγκρισης embeddings |
| `results/step4/` | Σύγκριση μοντέλων, αποτελέσματα ανά περιγραφή |
| `webapp/` | Σελίδα αναζήτησης (Streamlit) |
| `docs/PROMPTS.md` | Τα βασικά prompts προς τον coding agent |
| `docs/dev_queries.json` | Οι 20 περιγραφές-δοκιμής για την επιλογή μοντέλου |

## Εκτέλεση

```bash
python3 src/split_senses.py          # χρειάζεται data/raw/modern-greek-dictionary.parquet
streamlit run webapp/streamlit_app.py  # χρειάζεται HF_TOKEN και DATA_REPO
```
